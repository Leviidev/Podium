# Podium

Podium is an **iPod Touch** emulator for iOS. Currently, these are the supported iOS versions:

| Device               | iOS Version |
| -------------------- | ----------- |
| iPod Touch (4th Gen) | iOS 6.1.6   |

## Enabling JIT

| iOS Version        | Method                                                   |
| ------------------ | -------------------------------------------------------- |
| iOS 17.4+          | StikDebug                                                |
| iOS 17.4 and below | 🚫 No currently supported method for JIT; may still work |
